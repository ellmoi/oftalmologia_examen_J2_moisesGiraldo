## 1. Visión general del repositorio

Este repositorio conserva la base del proyecto de oftalmología y glaucoma, además del desarrollo específico del examen de seguimiento y control de presión intraocular.

La entrega final se organiza de forma clara para diferenciar:

- el proyecto base del taller;
- la documentación de apoyo;
- la solución del examen 2.

## 2. Ramas del repositorio

- `main`: rama base del proyecto con la configuración inicial.
- `trabajo-final`: rama de entrega del taller base y la base de datos.
- `examen-2`: rama de desarrollo del examen 2 de presión intraocular.

## 3. Desarrollo del examen 2

La solución completa del examen se encuentra en el archivo [DESARROLLO_EXAMEN_2.md](DESARROLLO_EXAMEN_2.md).

Este documento incluye la evidencia del desarrollo de los seis puntos evaluativos del taller:

1. Análisis del modelo relacional.
2. Consultas básicas.
3. Consultas relacionales.
4. Consultas avanzadas.
5. Vista `vw_patient_pressure_statistics`.
6. Función almacenada `fn_pressure_difference`.

> La documentación se mantiene ordenada y separada para preservar la evidencia del taller base y la evidencia del examen de presión intraocular.
